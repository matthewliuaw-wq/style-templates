# style-templates · 公众号内容样式库

五套可直接填充的公众号视觉样式 + 一套导读文章写作模板 + 全部渲染工具链。
**给 AI 用法和给人用法写在同一页:指令全部可复制粘贴,交给 Claude Code 执行即可。**

---

## 一句话起步

把下面这句贴给你的 Claude Code(地址换成你的克隆位置):

```
帮我 clone https://github.com/matthewliuaw-wq/style-templates 到 ~/Documents,
然后读它的 README.md,我要做一篇氛围编程培训的活动总结
```

Agent 会按本 README 自动:装依赖 → 按决策表选样式(培训总结 → 02 IKB)→ 复制模板 → 引导你给内容 → 渲染出成品。

## 环境自检(agent 首次使用先跑)

```bash
pip3 install Pillow markdown premailer   # 三个包,一次性
ls "/Applications/Google Chrome.app"      # 渲染依赖 Chrome,macOS 标配
```

渲染命令一律 `python3`(普通 python3 均可,无需特殊环境)。

## 你要做的事,分两种模式

### 模式 A · 导读/解读文章(内容为主的长文)

比如:报告解读、文章导读、深度翻译。

1. **内容结构**按 `样式模板库/文章导读模板包.md` 写:
   - 系列总序 → 导读(经验激活/对比卡/警告框,RG-1~5 模板)→ 正文 → 讨论 → 镜像(四模块:核心洞察/这告诉你什么/可以做什么/设计讨论问题)
2. **视觉样式**用 `01-anthropic-暖色`:复制其 `gen_html.py` 到文章目录,改顶部 `MD`/`OUT` 文件名
3. **出文**:`python3 gen_html.py` → 产物 HTML 全选复制,贴公众号后台

### 模式 B · 版式成品(视觉为主的交付物)

比如:培训通知、招生简章、项目总结长图、工具教程图。

1. 按下面**决策表**选样式
2. 复制该样式目录,按其 `使用说明.md` 的**模块地图**替换文字与图
3. 出活:
   - 全页 PNG:`python3 样式模板库/出全页图.py 源.html 成品.png [宽度]`
   - 公众号 HTML(02/03/04):跑对应样式目录里的内联生成脚本

## 常见坑(写进各使用说明,agent 注意)

- **进公众号的完整规则**(什么直贴、什么转图、什么转 GIF、SVG 交互怎么做)见 `样式模板库/公众号适配指南.md`
- 公众号后台只认 inline `style=""`,HTML 形态必须过内联脚本,别直接贴原始 HTML
- 全页图源码里**禁用 `position:fixed`**(钉视口底,裁边失效),装饰元素用 `absolute`
- 全页图内容高度上限 16000px,超长拆两张
- 微信单图 ≤10M,超长全页图建议 ≤5M
- 03/04 出公众号版走 `gen_zine_wechat.py` 同款管道(变量展开 → 缩放 → premailer),别手改

## 更新方式

本仓库就是模板本体:改完 `git add && git commit && git push`,使用方 `git pull` 即得最新。
新增样式按 `样式图册.md` 的扩展规范登记。
