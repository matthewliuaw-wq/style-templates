# 01 · Anthropic 暖色 · 使用说明

**驱动方式**:脚本驱动(md 源 → 公众号 inline-HTML)
**默认渲染**:公众号 HTML(贴后台)
**适用主题**:深度解读、报告翻译、叙事长文
**实战记录**:01-Claude-Tag / 02-从我的AI到我们的AI / 03-Economic-Index 二部曲

## 一句话用法

写好 md → 复制本目录 `gen_html.py` 到文章目录 → 改顶部 `MD`/`OUT` 文件名 → 跑 → 产物 HTML 全选复制贴公众号后台。

```bash
python3 gen_html.py    # 依赖安装见仓库 README「环境自检」
```

## 设计系统摘要

| Token | 值 | 用途 |
|---|---|---|
| 米 | `#F0EEE6` | 页面底色 |
| 暖墨 | `#2A2825` | 正文/标题 |
| 陶橙 | `#DA7756` | 强调/表格头/边线 |
| 块底 | `#E6E2D6` | 引用块/代码底 |

- 正文 16px / 行距 1.85;H2 带陶橙下边线
- CSS 内嵌在 `gen_html.py` 里,premailer 自动全量内联

## 内容约定(md 源)

- 顶部 `<!-- ... -->` 发布信息块(主标题/摘要/配图清单),脚本自动剥掉
- CJK 之间粗体用 `<strong>`,不用 `**`
- 全角标点写稿时直接用
- 脚注用行内 `<sup style="font-size:12px;color:#8B7D72;">[n] …</sup>`
- 图片相对路径 `images/xx.png`,贴后台后需逐张手动上传

## 注意

- `gen_html.py` 以本目录这份为准(源自 media-article-composer skill 的版本,已快照入库,改这里即更新)
- 写稿规范(全角标点、`<strong>` 粗体、脚注内嵌)见上方「内容注意」与 `样式模板库/公众号适配指南.md`
