# 03 · zine 杂志风 · 使用说明

**驱动方式**:手工填充(直接改 HTML 文字与图)
**默认渲染**:**双输出**——全页 PNG(1080px,整图发布)+ 公众号 HTML(缩放内联,贴后台)
**适用主题**:项目复盘、工作总结、活动回顾——有"幕次"感的叙事内容
**实战记录**:9月20日"两日总结"(1080×14476,原版留在本地,含借用素材不入库)/ 9月28日 研修班回顾(**模板示例即此版**,零借用素材,双输出)

## 用法(五步)

1. 复制 `模板示例.html`(研修班回顾版)为新文件(如 `十月复盘.html`),放同目录(图片相对路径才不断)
2. 按**页面标记**逐段替换文字:HTML 里有 `<!-- ═══ P.01 封面 ═══ -->` 这样的分页注释,一页一页改
3. 换图:替换 `<img src="…">`,配图容器有 `duo`(原色微调 + 墨线边框)和 `plate`(错位硬块)两种装置,见下
4. 出全页图:

```bash
"/Users/liuyuxin/Documents/Vibe Coding项目/PPT制作练习/ppt-master/.venv/bin/python" ../出全页图.py 十月复盘.html 十月复盘.png 1080
```

5. (可选)出公众号 HTML:复制 `gen_zine_wechat.py` 到文章目录,改顶部 `SRC`/`OUT` 文件名后跑——脚本自动做三件事:展开 CSS 变量(含内联 style)、1080px 设计等比缩放到 677px 正文宽(×0.627)、premailer 全量内联。产物直接贴后台。

## 设计系统摘要

| Token | 值 | 用途 |
|---|---|---|
| 纸 | `#F5EFE0` | 底色(带 9px 网点纹理) |
| 藏青 | `#1E4DBC` | 主专色 |
| 砖红 | `#C8553D` | 副专色(错位、下划线) |

**五个核心装置**(都在 `<style>` 里有现成类,套 class 即用):

| 装置 | class | 效果 | 怎么用 |
|---|---|---|---|
| 原色图框 | `.duo` / `.duo-brick` | **照片保留原色**,仅轻调对比饱和(+墨线边框);2026-09-28 起弃用专色双色 | `<div class="duo"><img src="…"></div>`,高度写在 style |
| 错位硬块 | `.plate plate-navy/brick` | 边框 + 右下实色错位层(印刷套版不准感) | 包住任意内容块 |
| 错位字影 | `.misreg-navy/brick` | 大标题文字带异色投影 | 加在 display 大字上 |
| 幕次标签 | `.act-tag`(可加 `.brick`) | 专色块白字"第 X 幕 · XX" | 每幕开头 |
| 虚线分割 | `.cut` + `<span>` | 分页虚线 + 页码字 | 页与页之间 |

其他:粗砖红下划线强调(`<b>`)、`mono` 等宽小字、`chips` 关键词标签、`wall` 四格图墙。

## 区块地图(按 P.0N 分页)

- **P.01 封面**:报头条(日期/期号)→ 封面印章(`cover-seal`,4 字方章)→ 大字主题(`cover-flow`/`cover-line` 错位字影)→ 关键词行 → 落款条
- **P.02 设问**:提出问题,引出正文
- **P.03 起 各幕**:统一节奏 = `act-tag` → 错位大标题 → 正文段 → `plate/duo` 配图 → 图注;幕与幕之间用 `cut` 分割
- **中段可插**:四格图墙(`wall`)、要点清单、数据条
- **结尾**:总结金句 + 出品落款

## 注意

- 1080px 固定宽,是手机竖版的全尺寸;不要改 `html,body{width:1080px}`
- `duo` 专色处理对**高对比、构图清晰**的照片效果最好;文字多的截图会糊,改用普通 img
- 图片体积大时出图前先压缩(微信单图 10M 限,超长图建议 ≤5M)
- 全页超高(>16000px)会被 Chrome 钳制,极长内容拆两张图
