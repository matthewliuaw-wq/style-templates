# 一个文件夹的知识之城 · 使用说明

> 九月十九日「项目三·图片生产线」演示配套可视化作品。
> 主题：一个本地文件夹，如何作为知识库，喂出一场教学演示。

## 怎么打开

双击 `index.html` 即可（无需联网，字体用系统字体，素材全部本地）。

- **地铁图**：点击任一站点，下方展开它与演示的关系说明；站名旁的「原文 ↗」回到 X 原帖。
- **视频**：第三幕三段视频直接点播，均出自知识库收录文章的原文配图。

## 文件构成

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本体（母版：设计、线路走向、动画） |
| `assets/` | 素材：海报图、VOL 风格墙、三段视频 |
| `build/scan.py` | 数据生产线：扫描知识库文件夹，把真实数字与链接注入页面 |
| `知识之城-全页长图.png` | 全页长图快照（公众号、转发用） |

## 重跑（数据更新）

知识库文件夹变了之后，重跑一次脚本，页面的数字与链接随之更新：

```
python3 build/scan.py
```

页脚的生成日期会同步更新——这个页面本身，就是用「母版＋要素表」的方式生产的。
