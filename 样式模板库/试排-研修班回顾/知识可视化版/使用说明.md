# 05 · 知识可视化 · 使用说明

**驱动方式**:手工填充(改 index.html 的 SVG 城市插画与各区内容)
**默认渲染**:网页(可交互,含视频位);全页 PNG(1440px 宽)用于微信整图发布
**适用主题**:知识体系全景、课程地图、成果总览——"一堆东西怎么连成一座城"
**实战记录**:9月19日"知识之城"(1440×8660)

## 这套模板的核心价值

**隐喻映射法**:把知识体系画成一座扁平插画风的城市,每个城区 = 一类内容。SVG 里注释齐全(`<!-- ── 源头港(血缘)── -->`),换主题就是换一套城区命名:

| 原城区 | 原含义 | 换主题示例(如"课程体系") |
|---|---|---|
| 源头港 | 素材/血缘来源 | 通识基础课 |
| 范本街 | 同类范本 | 参考课程 |
| 中央站 | 今天的演示 | 核心课程 |
| 方法巷 | 方法路线(三条路) | 教学方法 |
| 产业区 | 行业生产线 | 行业应用 |
| 工程桥 | 工程化路线 | 项目实践 |
| 镜像湖 | 同构映射 | 迁移复用 |

## 用法

1. 整目录复制为新项目(本目录已去 mp4 视频,视频位由海报帧图顶住)
2. 改 `index.html`:
   - **城区命名**:搜 SVG 注释定位各区,改建筑上的文字标签
   - **标题区**:天空留白处的标题(`hero` 区,字体安全负空间已留好)
   - **各城区详情卡**:`hero` 之后的 section,逐区一段
3. 出全页图:

```bash
python3 ../出全页图.py index.html 知识之城-新主题.png 1440
```

## 注意

- SVG 城市插画是**手工绘制**的(云/飞鸟/电车/齿轮/小人都有注释分组),大幅改构图成本高;**换文案便宜,换布局贵**——优先换文案
- 原完整版(含 mp4)在桌面 `9月19日项目演示/知识库可视化/`;`build/scan.py` 是当时的资产扫描脚本,可参考
- 1440px 宽(比 zine/教学宽一档),因为插画细节多;若嫌字小可整体 2× 出图
- 微软雅黑缺失环境会回退,正文用了本地安全字体栈,不用动
