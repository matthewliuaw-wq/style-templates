# 公众号适配指南 · HTML 成品怎么进微信

HTML 模板做完,进公众号只有三条路。**先选路,再做稿**——每条路对源文件的要求不同。

依据:本库三篇实发文章的经验 + 公众号编辑器公开实测规则(参考:知乎《详细教你微信公众号正文页 SVG 交互开发》)。

---

## 一、三条路,怎么选

| 路 | 产物 | 适用 | 代价 |
|---|---|---|---|
| **A · inline HTML 直贴** | 可选中、可复制的正文 | 文字为主(导读/解读/详情页)——01/02 的默认路 | 图片要逐张传素材库 |
| **B · 整图(静态 PNG)** | 一张全页长图 | 视觉优先(zine/教学/知识全景);追求 100% 还原 | 文字不可复制、不可放链接 |
| **C · 动图/交互** | GIF 或 SMIL 交互 SVG | 动效、点击交互(拆红包/翻牌/地铁图点击) | 改造成本最高,公号只认 SMIL |

**一句判别**:要"读"选 A;要"看"选 B;要"玩"选 C。

---

## 二、什么内容转什么(对照表)

| 你的内容 | 进公号的正确形态 | 说明 |
|---|---|---|
| 正文/标题/引用/表格 | **A · inline HTML** | 唯一可检索可复制 |
| 静态数据图表 | **B · PNG**(嵌在 A 里) | ECharts/JS 图表公号跑不了,截图 |
| JS 交互图(如地铁图) | **B · 全页 PNG + 信息板** | 公号禁 `<script>`;交互信息用静态版补全(知识可视化版已内置"线路一览"就是这个原因) |
| 视频 | 后台**视频卡片**(本地上传/腾讯视频链接)或 **GIF ≤10M** | 正文嵌不了 mp4;短循环动效转 GIF |
| hover/滚动进场动效 | **GIF** 或放弃 | 公号不执行 JS 动效 |
| 点击交互(翻牌/解锁/展开) | **C · SMIL SVG** | 公号正文原生支持,见下节 |
| 超链接 | 仅公众号文章互链 | 外部链接只能放文末"阅读原文"处 |

## 三、编辑器硬规则(agent 出稿前自查)

### 被 strip 的(写了一定丢)

- `<style>`、`<script>`、`<a>` 标签;`class`/`id` 属性;`@font-face`
- CSS 变量 `var()`:必须先展开成具体值(01-04 的生成脚本已内置)
- `position:fixed`(全页图渲染也废,统一用 `absolute`)

### 活下来的

- 元素级 `style="..."`(全部样式唯一载体)——01/02/03/04 的内联管道干的就是这个
- `<strong>`(CJK 粗体唯一可靠写法,`**` 会失效)
- `<svg>` + **SMIL 动画**(`<animate>`/`<animateTransform>`,`begin="click"` 触发点击交互)

### 潜规则(踩过才知)

- `background:url(...)` **地址不能带引号**,带就整条被滤
- 正文**必须有文字**,纯长图也先敲一行字
- 安卓端点击动画可能出诡异边框:相关 `<g>` 全加 `style="outline:none"`
- SVG 交互素材导出时选 **Presentation Attributes**(不生成 `<style>`)
- 图片相对路径进不了公号:mdnice 自动传图床;手动路 = 素材管理上传拿线上地址,再 DevTools 替换
- 尺寸:封面 2.35:1 单独传;单图(含 GIF)≤10M;GIF 建议宽度 640-750px

## 四、本库五套样式的推荐进法

| 样式 | 首选 | 备注 |
|---|---|---|
| 01 暖色 | **A**(gen_html.py → 公众号版) | 图逐张传 |
| 02 IKB | **A**(gen_ikb_wechat.py → 公众号版) | 同上;`.ikb-end` 负外边距待后台实测 |
| 03 zine | **A 或 B 双输出** | 公众号版走 gen_zine_wechat.py(缩放内联);要 100% 错位/巨字效果选全页 PNG |
| 04 教学风 | **A 或 B 双输出** | 同 03;巨字织入在 PNG 里最保真 |
| 05 知识可视化 | **B(全页 PNG,`?static=1` 直显)** | JS 交互进不去;想保点击交互需改写 SMIL SVG 版(另立项);静态版靠"线路一览"补全信息 |

## 五、发布快查(两条操作路)

**mdnice 路(最省事)**:md/HTML 贴 [mdnice](https://mdnice.com) → 图自动传图床 → 复制进后台。

**DevTools 路(精细控制)**:后台正文先敲两行字 → Chrome DevTools 定位第二行 → Edit as HTML → 整段替换成内联产物 → 空白处点一下固化。偶尔被自动撤销,重贴一次即可。
