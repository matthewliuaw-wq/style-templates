# 02 · IKB 瑞士风 · 使用说明

> ⭐ **首推场景:氛围编程培训的通知、招生、总结、回顾**(图册决策表第 1 行)

**驱动方式**:脚本驱动(网页版 HTML+CSS → 公众号 inline-HTML)
**默认渲染**:公众号 HTML(贴后台);网页版本身也可直接浏览器预览
**适用主题**:课程详情、招生简章、活动回顾、成果展示——信息密度高的结构型文章
**实战记录**:05-公众号排版样例(氛围编程研修班项目详情)

## 用法(三步)

1. **复制本目录**,改名为新文章目录
2. **改 `模板示例.html` 的文字**(区块地图见下),图片换成新文章的(放 `assets/images/`,改对应 `src`)
3. **出公众号版**:改 `gen_ikb_wechat.py` 顶部 `SRC_HTML`/`OUT` 路径,跑:

```bash
python3 gen_ikb_wechat.py    # 依赖安装见仓库 README「环境自检」
```

产物样式全 inline,全选复制贴后台。(脚本做三件事:展开 CSS 变量、手机优先合并、premailer 内联。)

## 区块地图(模板示例.html)

```
<article class="ikb-article">
├── .ikb-cover        封面蓝块:kicker(英文眉线)/ h1(机构+主标+副标)/ dek(一句话)/ foot(编号+落款)
├── .ikb-hero         首图 + 图注(.ikb-caption)
├── .ikb-section ×N   章节,每节 = .ikb-section-head(编号+标题+蓝底线)+ 内容块
│   ├── .ikb-copy         正文段落
│   ├── .ikb-info-grid    信息栏(标签在上、值在下,一行一条)
│   ├── .ikb-index        并列特点(编号+小标题+说明,一行一条)
│   ├── .ikb-phases       阶段列表(阶段标+标题+概括+编号条目)
│   ├── .ikb-fact-rail    四格数据条(手机端自动 2×2)
│   ├── .ikb-statement    克莱因蓝结论带(英文眉线+大字结论)
│   ├── .ikb-practical    报名信息(标签/值行;首行大数字)
│   └── .ikb-note         灰底注意事项(蓝顶线)
└── .ikb-end          黑色结尾块(大标题+一句话)+ .ikb-source 来源说明
```

章节增删:整个 `<section class="ikb-section">…</section>` 复制/删除即可,编号手动改。

## 设计系统摘要(2026-09-28 定稿版)

| 项 | 值 |
|---|---|
| 纸/墨/线/灰 | `#FAFAF8` / `#0A0A0A` / `#D4D4D2` / `#737373` |
| IKB 克莱因蓝 | `#002FA7`(唯一饱和色) |
| 正文 | 16px / 行距 1.7 / 苹方 |
| 章节编号 | Georgia Bold **40px**(手机 38px)老式数字,克莱因蓝,与标题同行基线对齐 |
| 英文眉线 | Georgia Bold 12px + 字距 .08em~.12em |
| 章节间距 | 32px(手机 30px),密度已两轮收紧 |
| 兜底字体栈 | `Georgia, "Times New Roman", "Noto Serif", serif`(安卓落 Noto Serif,数字变齐线,气质保住) |
