# 04 · 教学步骤风 · 使用说明

**驱动方式**:手工填充(HTML 源,语义分节 + 可复用模块类)
**默认渲染**:全页 PNG(1080px 宽,整图发布);**另可出公众号 HTML**(走 zine 同款缩放内联管道,见下)
**适用主题**:工具教程、Skill 介绍、操作指南——"是什么→怎么用→照着做"的教学内容
**实战记录**:9月20日 Playwright MCP 长图(SVG 旧版)/ 9月28日 研修班回顾(HTML 新版)

> 2026-09-28 结构升级:源从固定坐标 SVG 改为语义 HTML(旧 SVG 存档为 `存档-旧版-SVG源.svg`)。
> 好处:增删章节不动坐标、模块类可复用、一源双出(PNG + 公众号 HTML)。

## 用法(三步)

1. 复制 `模板示例.html` 为新文件
2. 按**模块地图**替换文字(全部内容在语义标签里,搜中文即改)
3. 出全页图:

```bash
"/Users/liuyuxin/Documents/Vibe Coding项目/PPT制作练习/ppt-master/.venv/bin/python" ../出全页图.py 新教程.html 新教程.png 1080
```

## 模块地图(class 前缀 `t-`,按页序)

| 模块 | class | 结构 |
|---|---|---|
| 页眉 | `.t-head` | kicker / h1(衬线大标)/ sub / rule |
| 巨字区(可选) | `.t-bigchar` + `.t-weave` | 巨字轮廓(ghost+outline 双层)+ 织入行(mono 六色阶) |
| 章节骨架 | `.t-sec` + `.t-sec-head` | 章印(壹贰叁,红底)+ 标题 + 底线 |
| 概念定义 | `.t-def` | term(mono)+ desc,多组堆叠 |
| 结论条 | `.t-callout` | 米卡 + 红左线 + 居中金句 |
| ✕/✓ 对照 | `.t-vs` | 双栏 box(`.good` 高亮右栏) |
| 代码块 | `.t-code` | 米底 mono 行 |
| 装裱图框 | `.t-fig` | 米卡衬边装裱 + mono 图注(左描述右"图 n-n");放在任意步骤/章节后 |
| 步骤说明 | `.t-step-label/-note` | 标号行 + 说明(em 红字强调) |
| 四象限卡 | `.t-grid2` + `.t-card` | 2×2,卡内 cmd(mono)+ note |
| 流程胶囊 | `.t-flow` + `.t-pill` | 竖排胶囊(dark/lite/end 三态)+ ↓ 箭头 + `.t-loop` 虚线回环 |
| 案例卡 | `.t-case` | 标题 + 引文 + who |
| 编号要点 | `.t-point` | 红框序号(一二三)+ 标题 + 说明 |
| 适用判断 | `.t-fit` | ✓/✕ 双栏 |
| 页脚 | `.t-foot` | rule + 结语 + 红章 + credit |

**增删章节**:整个 `<section class="t-sec">…</section>` 复制/删除,章印汉字手动改;巨字区整个 `.t-bigchar` 可整块删除。

## 设计 Token

| Token | 值 | 用途 |
|---|---|---|
| 纸 | `#F5F1E6` | 底色(带轻噪点) |
| 墨 | `#26231D` | 标题主字 |
| 蓝 | `#1E4E79` / `#33658A` / `#7FA3C4` | 代码/术语三阶 |
| 红 | `#AE3B32` | 章印、警示、回环线 |
| 卡 | `#EFE9D9` + 边 `#C9C0AC` | 卡片底 |
| 正文 | `#4A463C` | 段落 |

字体:衬线 `Noto Serif SC/Songti SC`(标题、章印);mono `SF Mono/Menlo`(代码、织入行);正文苹方。

## 出公众号 HTML(可选)

复用 03 zine 的管道脚本(缩放 0.627 + 变量展开 + premailer):复制 `03-zine-杂志风/gen_zine_wechat.py`,改顶部 `SRC`/`OUT` 指向本文即可。

## 注意

- **`position:fixed` 禁用**(四角装饰线等用 `absolute`)——fixed 元素钉在截图视口底,会导致全页图裁边失效
- 巨字区织入行每行一个 `div`,六色阶 class `w1-w6` 交替用
- **配图用 `.t-fig` 装裱图框**(2026-09-28 起):`<figure class="t-fig"><div class="mount"><img src="…"></div><figcaption class="cap"><span>描述</span><span>图 n-n</span></figcaption></figure>`,图注编号按"章-序"(图 3-2 = 第叁章第 2 图);照片建议横构图,竖图会被 object-fit 裁中段
- 微信单图 ≤10M;配图后 PNG 通常 2-5M,仍无忧
